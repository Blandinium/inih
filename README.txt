> This is a fork of [benhoyt/inih](https://github.com/benhoyt/inih), with C++ wrapper extensions.
> Starting with **r30**, each upstream release through **r61** has a corresponding
> **rNcpp** tag (for example, **r36cpp** for **r36**). These C++ releases support C++98
> and include `GetSections()`, `GetFields()`, and safe copying.
> Run `sh cpp/tests/run.sh` to build and test the wrapper.


inih is a simple .INI file parser written in C, released under the New BSD
license (see LICENSE.txt). Go to the project home page for more info:

http://code.google.com/p/inih/
